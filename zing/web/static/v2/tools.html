嵌入和重排端点返回的是向量或排名而非对话，因此不走对话检测，而用专门的探针核验。

  • 关键信号对照所声称模型的向量维度：货不对板的头号信号。
  • 辅助确定性与可区分性复测作为佐证。
  • 重排用已知答案探针：显而易见的答案必须排在首位。

协议
嵌入与重排端点只走 OpenAI 兼容接口。

不填则使用 zing 内置探针：一个问题加几段文档，其中唯一显而易见的答案应被排在首位。若要自定义，填入查询、每行一段文档，并指定预期排首位的文档行号（从 0 起）。

请求在 你本地的 zing 服务 发起，密钥只用于连接目标中转站，不上传任何第三方。

嵌入/重排是黑盒非对话检测：维度不符是最强的“货不对板”信号；确定性与可区分性是辅助证据。
