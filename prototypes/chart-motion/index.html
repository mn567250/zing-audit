      What the layer does and does not do

      Accessibility

      • No element added or removed, no ARIA attribute touched. The role="img" name, description and data tables stay as they are.
      • Temporary class and styles are removed after about 1 s, so the chart at rest is the same DOM as today.
      • Reduced motion: no class is set and the CSS sits behind no-preference.
      • Every motion is under 1 s and runs once (no pause control needed, WCAG 2.2.2).

      Performance

      • CSS animations only: opacity, transform, stroke-dashoffset. No requestAnimationFrame loop.
      • No layout reads: marker positions come from the path data, the line length from pathLength="1".
      • Heat grid: one CSS animation per cell, changing only its fill. 1-hour blocks (168 cells) cost a couple of slow frames at 4× CPU slowdown, mostly from drawing the grid itself.
      • The p25–p75 band grows out of its line with an SVG <animate> on the path, which works in every current browser. It is removed again after the motion.
